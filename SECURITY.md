# Безопасность LanVault

Поддерживаемая публичная ветка: **0.4 beta**, Android 10+ и Windows 10/11 с WebView2 и локальным NTFS-архивом. Linux и доступ из интернета не поддерживаются.

О найденной уязвимости сообщайте через **Security → Report a vulnerability** в этом репозитории. Если закрытая отправка недоступна, создайте issue с просьбой предоставить приватный канал, без описания эксплуатации, секретов и пользовательских файлов. При подготовке репозитория владелец должен включить Private vulnerability reporting.

Для сообщения полезны версия, платформа, шаги на синтетических данных и ожидаемое поведение. Не прикладывайте QR-подключение, токены, каталог состояния, приватные ключи подписи или личные фото. Ошибки обычного интерфейса можно сообщать публично.

## Модель защиты

- Первичное доверие: QR с локальным CA и случайным секретом, затем сравнение кодов и одобрение на ПК. Обнаружение в сети не заменяет проверку сертификата.
- Передача: HTTPS, проверка имени и SPKI CA, отдельный отзываемый токен устройства, без HTTP-перенаправлений и сетевого proxy.
- Сеть: выбранный частный физический адаптер Windows и Wi-Fi Network Android. Если VPN запрещает локальную сеть, LanVault сообщает ошибку; автоматического обхода kill switch нет.
- Состояние: Windows DPAPI и ограниченный ACL; Android AES-GCM / Keystore. Файлы доверия не предназначены для переноса между чужими пользователями ОС.
- Запись: полная SHA-256, проверенные NTFS-handles, staging и публикация без перезаписи. Чужое устройство не может читать состояние или отменять загрузку другого.
- Незавершённые задания: до 16 на устройство, 320 суммарно; неактивные задания истекают через сутки. Активная запись и durable commit не удаляются очисткой. Отмена завершённого файла запрещена.

## Ограничения beta

Сам архив хранит обычные оригинальные файлы с исходными метаданными, включая GPS, если он присутствует. Дополнительного шифрования архива средствами LanVault нет. Доступ определяется правами Windows и настройками диска. Скомпрометированное доверенное устройство или учётная запись ОС выходят за границы защиты.

Обычная синхронизация использует кэш подтверждений до суток. **«Проверить и восстановить копии»** повторно проверяет SHA-256 копий доступной сейчас медиатеки телефона, не используя этот кэш. Для файлов, оригинал которых уже удалён с телефона, восстановление из телефона невозможно.

Windows-beta пока не подписана Authenticode. Скачивайте пакет со страницы Releases данного проекта и проверяйте SHA-256. Android release APK подписывается постоянным ключом; fingerprints и история ротации публикуются отдельно. Debug APK не является публичным релизом.

Автоматические тесты и проверка advisories не заменяют независимый аудит. Ограничения испытаний и сценарии ручной проверки перечислены в [матрице beta](docs/testing/beta-matrix.md).
