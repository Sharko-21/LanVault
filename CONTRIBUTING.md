# Участие в разработке

Условия использования исходников — [MIT](LICENSE). Обычные ошибки и предложения принимаются через Issues; уязвимости — по [SECURITY.md](SECURITY.md).

Пишите файлы в UTF-8. Не добавляйте runtime-состояние, QR, токены, журналы личных устройств, ключи или абсолютные пути своего компьютера. Секреты подписи поступают только из локального защищённого хранилища или GitHub Actions secrets.

Перед изменением протокола проверьте совместимость с уже установленным клиентом. Не меняйте applicationId, alias Keystore, идентификаторы архивов, формат существующего доверия или подпись APK без плана обновления. Добавочные таблицы БД должны быть идемпотентны и сохранять возможность прочитать существующее состояние.

Проверки описаны в README. Изменения безопасности записи и восстановления требуют настоящих Windows/HTTPS-тестов. Изменения Android-провайдеров, разрешений и фонового режима также требуют проверки на устройстве; успешная сборка instrumentation APK не считается выполнением instrumentation-тестов.
