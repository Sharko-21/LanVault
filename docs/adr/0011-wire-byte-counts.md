# ADR-0011 — точные 64-битные размеры в JSON

Статус: **Accepted**, уточнение реализации этапа 2.

JSON-числа читаются JavaScript как Number и теряют целочисленную точность выше 2^53−1. Размеры и смещения в wire DTO и IPC передаются каноническими десятичными строками. Внутри используются Kotlin Long, Rust u64 с верхней границей i64::MAX и JavaScript BigInt.

Размер файла должен быть положительным; offset допускает ноль. Запрещены знак, ведущие нули, экспонента и пробелы. Общее верхнее ограничение — 9223372036854775807; эксплуатационный лимит размера будет меньше и настраиваться сервером.

Это сохраняет утверждённую 64-битную модель. Общие примеры в `protocol/compatibility-fixtures/uploads.json` проверяют точность и граничные ошибки. JSON Schema использует зарегистрированный формат `positive-int64`; он не должен молча игнорироваться валидатором.
