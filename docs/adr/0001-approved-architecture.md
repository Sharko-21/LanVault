# ADR-0001 — базовая архитектура

Статус: **Accepted**. Пользователь утвердил технический проект 4 ноября 2026 года.

Решения ADR-001…010 из проекта зафиксированы здесь одним исходным набором:

| ID  | Решение                                                                           |
| --- | --------------------------------------------------------------------------------- |
| 001 | Tauri 2 + React/TypeScript + Rust для Desktop                                     |
| 002 | Односторонняя модель; удаления источника не распространяются                      |
| 003 | QR, локальное TLS-доверие и отдельные токены устройств                            |
| 004 | Возобновляемые последовательные части внутри файла                                |
| 005 | Полный SHA-256, журналируемое завершение и устойчивое подтверждение               |
| 006 | Независимые Room и SQLite базы                                                    |
| 007 | Desktop работает в пользовательском процессе с треем; служба позднее              |
| 008 | Ограниченные фоновые Android-сессии и отдельный пользовательский длительный режим |
| 009 | Устойчивая идентичность хранилища и явная миграция папки                          |
| 010 | NTFS и дедупликация внутри устройства/хранилища первой версии                     |

Изменения фиксируются следующими ADR. Этот документ не означает реализации перечисленных функций.
