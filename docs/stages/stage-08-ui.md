# Этап 8: интерфейс Windows и Android

## Результат

Вместо общего длинного экрана появились отдельные рабочие разделы. Убраны рекламные заголовки, слоганы, крупные декоративные карточки и технические сведения рядом с основными действиями. Светлая и тёмная темы используют нейтральные поверхности, обычную типографику и один синий акцент.

### Windows

- **Архив:** число и объём сохранённых файлов, состояние приёма, папка и открытие её в Проводнике, текущие файлы с прогрессом, последние сохранения с размером и временем.
- **Устройства:** отдельный список с временем последней связи. Отключение требует подтверждения; список не выдаёт сохранённое доверие за состояние «онлайн».
- **Настройки:** папка, адаптер, включение приёма, тема. Версия протокола, идентификатор и отпечаток CA находятся в раскрываемой диагностике.
- QR-код расположен на белом фоне, увеличен до 320 px. Диалог показывает срок действия, обновление кода и отдельный шаг сравнения кодов.
- Скорость приёма рассчитывается за окно до 10 секунд по монотонному счётчику принятых байтов. Завершение отдельного файла не создаёт отрицательную скорость. Это скорость получения данных, а не скорость подтверждённого сохранения на диск.
- В списке файлов показываются понятные папки вида «Видео / 2026 / 09». Полный путь остаётся в подсказке.

### Android

- Нижняя навигация: **Копирование / Файлы / Настройки**.
- Главный экран ведёт через подключение, разрешения и копирование; показывает текущую операцию, файлы, прогресс и результат текущего запуска. Общий процент для медиатеки неизвестного размера не выдумывается.
- Ручная отправка вынесена в сетку миниатюр с выбором и закреплённой кнопкой отправки. Список загружается страницами, и число просмотренных файлов явно подписано. Оно не ограничивает полное копирование медиатеки.
- Миниатюры читаются через MediaStore: до четырёх запросов одновременно, кэш до 16 МиБ, отмена через CancellationSignal. Изменение разрешений пересоздаёт кэш.
- Фоновое копирование, проверка связи, разрешения и отключение компьютера находятся в настройках. Журнал последних передач доступен с главного экрана.
- Ограниченный доступ к медиатеке и отсутствие доступа к оригиналам отображаются отдельно. Коды ошибок скрыты в подробностях. Обычная сетевая ошибка больше не предлагает создавать новый QR-код.
- Экраны, компоненты, оформление и вспомогательные тексты отделены от Activity и логики передачи.

## Совместимость и установка

Протокол, схема SQLite/Room, Android applicationId, Keystore и формат доверия сохранены. VPN и привязка сокетов к физической локальной сети не изменялись. Путь Windows EXE остался прежним, поэтому исключение ASTER продолжает относиться к этому приложению.

Windows уже пересобран и запущен из `target/gnu/debug/lanvault-desktop.exe`. Существующий ярлык на рабочем столе запускает этот же файл. Приём восстановлен на `192.168.1.68:43827`, папка — `D:\Sync`.

Android: `artifacts/android/LanVault-0.3.0-ui-debug.apk`, versionCode **7**, versionName **0.3.0-ui**. Установить поверх текущего приложения, не удаляя его и не очищая данные. Сохранённый компьютер будет доступен без повторного QR. Для ручного запуска открыть «Копирование» → «Скопировать сейчас».

Windows проверен в работающем приложении: архив, настройки, светлая и тёмная темы, диалог QR. Пользователь подтвердил передачу с уже подключённого телефона после первого обновления. Финальная сборка повторно запущена с прежним LAN-адресом. Сравнение до/после последнего обновления подтвердило неизменность защищённой identity, текущих credentials, device IDs, выбранного архива и настроек приёмника: `artifacts/ui-continuity.json`.

На протяжении работы два старых разрешения Pixel были отозваны в работающем приложении; этот факт отражён в промежуточных снимках. Рефакторинг не восстанавливает отозванный доступ. Действующее подключение Pixel сохранено и использовано для проверки передачи.

ADB не обнаружил подключённых устройств. Новый Android UI проверен сборкой и lint; запуск нового APK, миниатюры на Pixel и увеличенный системный шрифт требуют проверки на телефоне. Существующие instrumentation-тесты собраны, но на устройстве не запускались.
