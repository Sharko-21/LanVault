# Этап 2 — структура проекта и сборочная база

Дата: **4 ноября 2026 года**, Europe/Moscow. Архитектура утверждена пользователем перед началом работы.

**Результат:** создан каркас двух приложений и настроены сборочные команды. Доступные локальные проверки пройдены. Полный платформенный Definition of Done этапа остаётся открытым до нативных сборок и испытаний на устройстве; APK/EXE не собраны, сетевой приёмник отсутствует.

## Не выполнено и почему

| Проверка                                                     | Причина                                                                   |
| ------------------------------------------------------------ | ------------------------------------------------------------------------- |
| Android assemble/lint/JVM tests                              | Нет JDK 17, Android SDK Platform 37 и Build Tools 36.0.0                  |
| Android instrumentation, MediaStore/NSD на реальном телефоне | Нет настроенного Android toolchain и подключённого тестового устройства   |
| Rust compile/test/clippy                                     | Нет полного Rust std/toolchain на PATH и MSVC/Windows SDK                 |
| Native Tauri EXE, системный диалог и трей                    | Те же отсутствующие зависимости; WebView2 обнаружен                       |
| Проверка пары Android ↔ Desktop                             | Передающий/принимающий протокол не реализован на этапе 2                  |
| TLS и защищённая запись NTFS                                 | Эксперименты остаются входной проверкой этапа 3, до открытия LAN listener |
| GitHub CI                                                    | Workflow подготовлен локально; не отправлялся в удалённый репозиторий     |

Ошибки native preflight не скрываются и не считаются успешной сборкой. Исходники Android и Tauri могут потребовать исправлений, выявляемых только компилятором и устройством.

## Запуск

Быстрый web-предпросмотр из папки lanvault:

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

Адрес: <http://127.0.0.1:1420>.

После установки toolchain:

```powershell
# Windows
pnpm dev:desktop
pnpm build:desktop

# Android
cd android
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:installDebug
```

Полные требования, проверки, пути выходных файлов и запуск на устройстве: [development.md](../installation/development.md).

Полный список добавленных файлов: [stage-02-files.txt](stage-02-files.txt). Локальные подробные логи находятся в игнорируемом `artifacts`; их наличие не требуется для сборки. Исходные пользовательские файлы не изменялись; все исходники проекта и workflow созданы заново.
