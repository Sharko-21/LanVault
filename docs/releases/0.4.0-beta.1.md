# LanVault 0.4.0-beta.1

Первая публичная beta для копирования оригиналов фото и видео с Android на Windows по локальной сети. Android 10+, Windows x64 с WebView2, архив на локальном NTFS-диске. Передача защищена TLS и требует подтверждения телефона на ПК. Интернет для копирования не нужен.

## Что исправлено

- Незавершённые загрузки больше не занимают очередь навсегда: добавлены срок хранения, очистка staging, отмена и отдельные квоты устройств. Активная запись и сохранённые файлы защищены от очистки.
- На Android добавлена команда «Проверить и восстановить копии»: она проверяет SHA-256 на ПК, обходя суточный кеш подтверждений, и повторно копирует доступные на телефоне утраченные или повреждённые оригиналы.
- Исправлено разрешение Tauri для открытия папки архива. Добавлен явный постоянный каталог состояния через `--state-dir`.
- Подготовлены release APK с постоянной подписью и историей ротации ключа, переносимый Windows-пакет, MIT, лицензии зависимостей, контрольные суммы и workflows CI/черновика выпуска.

## Обновление без повторного QR

Устанавливайте APK поверх текущей совместимой версии, сохраняя данные приложения. На Windows сохраните каталог состояния, identity, архив и аргументы ярлыка. Не запускайте два приёмника с одной БД. При исключениях VPN, привязанных к EXE, сохраняйте его путь.

На исходном Pixel и ПК проверено реальное обновление обеих сторон: компьютер остался сохранённым, копирование продолжилось без нового QR. Также сравнены identity, данные доверия и архив. Новая таблица lease добавляется совместимо с прежней схемой.

## Проверки и ограничения

Локально прошли Rust-тесты и Clippy, 31 frontend/контрактная проверка, 25 проверок настоящего HTTPS, 6 проверок жизненного цикла загрузок и 48 JVM-тестов Android. Собраны release-приложения и instrumentation APK, выполнены Android lint и проверки подписи на SDK 29/32/33/37. В проверенном графе Windows/Android и npm-зависимостях известных уязвимостей не обнаружено на момент подготовки. Публичный снимок проверяется на приватные файлы и секреты перед упаковкой.

Windows beta **не подписана Authenticode**; возможен SmartScreen. Сравнивайте файлы с `SHA256SUMS.txt`. Контрольная сумма проверяет целостность, но сама по себе не подтверждает издателя.

GitHub Actions подготовлены; их наличие не означает успешного запуска в GitHub. Instrumentation на эмуляторах, установка на чистую Windows, длительная работа на разных телефонах и потеря питания ещё требуют проверки. Полная [матрица испытаний](../testing/beta-matrix.md) и [модель безопасности](../../SECURITY.md) описывают границы beta. Это не независимый аудит безопасности; храните отдельную резервную копию важных данных.

Передача прерванного файла начинается заново. Фоновая работа зависит от ограничений Android. VPN должен разрешать локальную сеть. Восстановление проверяет текущую доступную медиатеку и не восстанавливает оригиналы, которых уже нет на телефоне.

Файлы выпуска: Windows x64 ZIP, Android APK, source ZIP и `SHA256SUMS.txt`. См. [установку](../installation/beta.md) и [сборку/выпуск](../installation/releasing.md).
