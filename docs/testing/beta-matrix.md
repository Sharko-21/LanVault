Публичная beta не обещает непрерывный фоновый запуск вопреки ограничениям Android или работу через запрет локальной сети сторонним VPN. Не используйте эти формулировки в описании релиза.

Для ручного upgrade-теста не удаляйте исходное приложение. Зафиксируйте выбранный компьютер, установите новый подписанный APK через `adb install -r`, убедитесь в сохранении UID/данных и отправьте синтетический файл на прежний ПК. Проверьте также новую команду восстановления после удаления и повреждения тестовой копии на ПК. Пользовательские оригиналы в отрицательных тестах не удаляются.
