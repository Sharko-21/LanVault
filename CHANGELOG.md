# Изменения

## 0.4.1-beta.1 — 2026-11-05

- Android сохраняет позицию после каждой полностью обработанной страницы медиатеки. После сбоя или закрытия приложения копирование продолжается с этой страницы, без повторного обхода всех предыдущих файлов.
- При временной сетевой ошибке повторяется запрос текущего файла с тем же идентификатором. Потерянный ответ о сохранении сверяется с сервером, прежде чем отправлять оригинал повторно.
- Для проверки сохранённого файла и ответа после загрузки выделен такой же бюджет ожидания, как для завершения большого видео. Проверка SHA-256 и сертификата сохранена.
- Добавлено однократное восстановление Wi-Fi-сессии после исчерпания повторов файла.
- Обновление совместимо с Windows 0.4.0-beta.1: сохранённый компьютер, подпись APK, данные доверия и архив остаются прежними.

[Подробности и ограничения выпуска](docs/releases/0.4.1-beta.1.md).

## 0.4.0-beta.1 — 2026-11-05

Первый публичный beta-выпуск для Android и Windows.

- Копирование доступной фото-/видеомедиатеки по локальной сети, до четырёх файлов параллельно.
- Сохранённое доверие, автоматическое подключение, история, системный трей и фоновые попытки Android.
- Проверка и восстановление копий без суточного кеша подтверждений.
- Срок хранения незавершённых загрузок, квоты устройств и безопасная очистка staging.
- Постоянная release-подпись APK с совместимой ротацией; Windows ZIP без Authenticode.
- MIT, лицензии зависимостей, SHA-256, CI и workflow выпуска кандидата.

[Подробности и ограничения выпуска](docs/releases/0.4.0-beta.1.md).
